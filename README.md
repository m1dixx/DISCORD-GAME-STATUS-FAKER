## **1. ЧЁ ЭТО ЗА ПРИЛОЖЕНИЕ**
Прога которая создает exe-файл с названием любой игры. Запускаешь его - Discord думает что у тебя запущена игра. Никакой магии, просто процесс с нужным именем. Код открытый, вирусов нет, собираешь сам. Если нашёл вирус - ты долбаёб и качал не с того репозитория.

## **2. НАХУЯ ЭТО НУЖНО**
Короче если вам тоже нехуй делать и вы хотите чтоб допустим у вас в дс 24 на 7 была запущена какая-либо игра - это ваш выбор.

**Конкретные причины:**
*   Показать игру, которой у тебя нет.
*   Не палиться, что ты смотришь ютуб, а не играешь.
*   Зайти в стрим, чтобы тебя занесло в категорию игры.
*   Просто поебать мозг друзьям.

## **3. КАК ЭТО РАБОТАЕТ**
Discord тупо смотрит список процессов в системе. Видит процесс с именем `csgo.exe` - показывает статус "В игре: CS:GO". Мы создаём процесс с точно таким же именем. Всё.

## **4. ПОЛНЫЙ ГАЙД КАК ПОЛЬЗОВАТЬСЯ**

### **4.1. Качаем и готовим**
1.  Качай файл `game.py` (исходник).
2.  **Переименуй его** в `НАЗВАНИЕ_ИГРЫ.py`. Название должно совпадать с `.exe` файлом игры:
    *   `csgo.exe` → `csgo.py`
    *   `javaw.exe` (Minecraft) → `javaw.py`
    *   `GTA5.exe` → `GTA5.py`

### **4.2. Ставим что нужно**
1.  Качай Python с [оф.сайта](https://python.org). **ВАЖНО:** в установщике галочка **"Add Python to PATH"**.
2.  Открой командную строку (Win+R → `cmd`).
3.  Введи команду для установки сборщика:
    ```bash
    pip install pyinstaller
    ```

### **4.3. Компилим в EXE**
1.  Открой командную строку **в папке с твоим `.py` файлом**.
2.  Введи команду (кавычки **обязательны** если в названии есть пробелы):
    ```bash
    pyinstaller --onefile "НАЗВАНИЕ ИГРЫ.py"
    ```
    Жди пока соберётся. Увидишь `Building EXE... completed successfully.` - готово.

### **4.4. КОПИРУЕМ ПУТЬ ОРИГИНАЛЬНОЙ ИГРЫ - САМОЕ ВАЖНОЕ**
Discord для некоторых игр проверяет не только имя файла, но и путь к нему. Нужно **скопировать структуру папок**.

**Как это работает:**

1.  Готовый `.exe` лежит в папке `dist`.
2.  **Переименуй сам `.exe` файл** в точное название оригинального `.exe` игры (например, `csgo.exe`).
3.  **Создай папку** с таким же названием, как папка, в которой лежит оригинальный `.exe` игры.
4.  Положи свой `.exe` в эту папку.

**Конкретные примеры:**

| Игра | Где лежит оригинальный .exe | Что делаешь |
| :--- | :--- | :--- |
| **Femboy Futa House** | `C:\Games\FEMBOY FUTA HOUSE\Femboy Futa House.exe` | 1. Переименуй `.exe` в `Femboy Futa House.exe`<br>2. Создай папку **FEMBOY FUTA HOUSE**<br>3. Положи `.exe` в неё |
| **Counter-Strike 2** | `C:\Steam\steamapps\common\Counter-Strike Global Offensive\game\bin\win64\cs2.exe` | 1. Переименуй `.exe` в `cs2.exe`<br>2. Создай структуру папок `\game\bin\win64\`<br>3. Положи `.exe` в папку **win64** |
| **Minecraft (Java)** | `C:\Program Files\Minecraft Launcher\runtime\java-runtime-gamma\windows\java-runtime-gamma\bin\javaw.exe` | 1. Переименуй `.exe` в `javaw.exe`<br>2. Создай папку **bin**<br>3. Положи `.exe` в неё |
| **Genshin Impact** | `C:\Program Files\Genshin Impact\Genshin Impact Game\GenshinImpact.exe` | 1. Переименуй `.exe` в `GenshinImpact.exe`<br>2. Создай папку **Genshin Impact Game**<br>3. Положи `.exe` в неё |

5.  Запускаешь `.exe` из этой новой папки.
6.  Проверяешь Discord.

## **5. ЧТО МОЖЕТ ПОЙТИ НЕ ТАК (И КАК ПОЧИНИТЬ)**

### **5.1. Проблемы и решения**
| Проблема | Решение | Почему |
| :--- | :--- | :--- |
| Discord не видит игру | Запусти `.exe` **от имени администратора** или **правильно скопируй путь** (см. выше) | Discord иногда проверяет путь к файлу |
| Статус пропадает через 5 минут | Просто перезапусти `.exe` | Discord сбрасывает неактивные процессы |
| Окно программы мешает | Сверни его — на статус не влияет | Главное, чтобы процесс работал |
| `.exe` сразу закрывается | Компилируй **БЕЗ** флага `--noconsole` | Консольному приложению нужна консоль |
| Не компилируется | Проверь, что Python в PATH и pyinstaller стоит | Иначе система не найдёт команды |

### **5.2. Важные особенности**
*   **Для игр из Steam/Uplay/Epic** почти всегда нужно копировать путь, иначе Discord не увидит.
*   **Нагрузка на систему:** ~0% CPU, ~10-20 MB RAM. Пустышка.
